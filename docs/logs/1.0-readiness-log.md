# 1.0 readiness assessment

Recorded 2026-09-15.

The three implemented CI adapters are not equally evidenced. GitHub Actions has replayable,
redacted real lifecycle captures; GitLab CI has controlled contract tests and one real
self-managed GitLab CE success experiment; Azure DevOps has controlled contract tests and a local
read-scoped PAT happy-path verification. The latter two do not yet have redacted, replayable
real-provider response corpora covering the full 1.0 contract, and GitHub still needs real
unknown/no-run, unauthorized, and upstream-failure evidence.

Implementation, controlled tests, replayable real-response fixtures, and optional live functional
experiments answer different questions. None substitutes for the others where the 1.0 commitment
requires real contract coverage. The next milestone is therefore to capture and redact
representative provider responses, replay them through the normal bounded panel route, and only
then change support wording. This entry clarifies current readiness; earlier logs remain the
historical record of the evidence available when they were written.
